4. What I could not verify, and what could go wrong

  1. OC4 acceptance is untested. These are the first brand-new forms put on this board. We never found the cause of the earlier board failure, so only a real run can answer this.
  2. The specimen form's lookup. It combines two patterns the pipeline already uses (the same-event lookup on the Veterinary form, and the 'current event' selector on Date of Visit). The combination itself has not been seen working in OC4. The validator flags that one helper row exactly as it flags the existing Veterinary form, which OC4 accepts; with the helper removed, the form validates clean.
  3. Nothing prompts staff to add Death Details when Outcome's vital status says deceased. That follows from add-when-needed.
  4. Run on a fresh study. I recommend new study identifiers (V4), as before, instead of re-running on the published V3 boards. Adding forms to an already published board has not been tested here.
  5. The earlier Follow-up and Outcome death rules are gone (date only after 'died of the cancer?', and so on), because the form only exists when a death has happened.
