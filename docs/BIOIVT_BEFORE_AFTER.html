2. Phase 1 (planned): Death Details and Specimen Collection

Specimen Collection goes on the same 7 events as the Short Form: Short Form Only visit, Lupus visit, Rheumatoid Arthritis visit, Psoriasis visit, Oncology visit, Covid-19 visit, Veterinary visit. Death Details goes on the existing common event Common (Cross-Visit) and is added only when someone has died (your decision). The earlier idea that death fields appear when 'Post-mortem sample' is ticked goes away: staff add the form instead.

3. Free text into choice lists: what is real today

The rules I propose (for your approval)

  1. Nothing becomes untypeable. Every converted field keeps an 'Other, specify' box.
  2. Coded plus verbatim. Where a code is chosen, the words staff typed are kept too.
  3. Where the values come from: a standard list if one exists (CDISC, RxNorm, SNOMED); otherwise a short list built from the values BioIVT actually sees and you approve.
  4. Numbers stay numbers. Lab values become numeric fields plus a unit list, not a choice list.
  5. Nothing is switched on until you have approved the actual values. Lists are plain files you can read.
  6. Old data is a separate step: existing free text gets matched to list values; anything unmatched goes to 'Other' with the original text kept.

The honest count

The audit table marked 89 fields as 'structure'. That label was too loose. By what the field is today: 45 are free text, 12 are numbers typed as text, and 32 are already pick lists that only need a different layout. So at most 45 fields would become choice lists, and only 2 conversions are live (medication name and donor diagnosis), both on demonstration lists, not verified codes: 25 medications and 7 diagnoses are verified; the larger lists in the test builds are samples that exist only to show how the search box feels. The medication route, frequency and unit lists are ready. For the rest, the values have not been designed.
